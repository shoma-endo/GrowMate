UI 変更の証跡を Playwright で採取してください。このステップはファイルを編集しません（Edit / Write は使えません。使える Bash は計測スクリプトだけです）。

手順:
1. 添付 `plan.md` の `UIモック:` ヘッダを見る。`対象外` なら UI 変更なしとして、スクリプトを実行せず `not_applicable` とする。
2. UI 変更がある場合、`plan.md` の「UI 既存パターン対照表」から、変更した画面の URL パスと、その行が写し元・共通化元にした既存の類似画面の URL パスを組にする。類似画面が無い行（新規）は対象だけを指定する。URL パスを推測で増やさない。
3. 次を実行する（組ごとに `--pair` を並べる。類似画面が無い組は `--pair /対象` だけ）。
   `npm run takt:ui-evidence -- --out {report_dir}/ui-evidence --pair /対象=/類似画面`
4. 終了コードで判定する。
   - `0`（対象画面にはみ出しなし）または `2`（対象画面にはみ出しあり）: `captured`。はみ出しの良し悪しはここで判断せず、レビュアーと final gate に渡す。
   - `3`（起動失敗・未ログイン等で採取できない）: `cannot_capture`。標準エラーの1行目をそのまま理由に書く。

レポートには、スクリプトの標準出力（Markdown）をそのまま貼る。表の行やスクリーンショットのパスを書き換えない。実行したコマンドと終了コードも書く。
