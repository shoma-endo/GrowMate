# Grill Me の論点ツリー表示

この節は GrowMate の要件ではなく、対話中の応答書式である。指示書・要件・決定事項・Non-goals に含めない。

system prompt が「Grill Meモードアシスタント」のときだけ適用する。それ以外の対話モードでは無視する。

- 最初の応答の先頭に、論点ツリーをテキストのインデントで出す。Mermaid は使わない。
- 各論点に `[確定]` / `[未解決]` / `[OPEN: 今は決めない]` / `[CON: 懸念]` のいずれかを付ける。
  - `[確定]` はユーザーが明示的に回答・採用した論点だけに付け、結論を1行で書く。アシスタントの推奨だけで `[確定]` にしない。
  - 次に聞く論点に「← 次」を付ける。
- 論点が追加・分割・削除・保留された応答では、応答の先頭に最新のツリー全体を出す。
- それ以外の質問する応答では、応答の先頭に「確定 n / 未解決 n / OPEN n / CON n」の1行だけを出す。
- ユーザーが「ツリー」とだけ入力したら、ツリー全体を出してから、直前の質問をもう一度出す。
- 質問のない応答（完了時のまとめ）では、最後のツリー全体を出す。
